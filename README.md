# 银行交易明细与信贷报告 PDF 重建及视觉版心检查交付工具箱

> 银行流水对账单与信贷调查报告 PDF 级重建、Word COM 高保真渲染、逐页切片生成、自动化版心排查与多维度视觉复核交付标准（Agent Skill）。
> 适用于银行对账单按 CSV 明细精准替换版式，以及大型信贷调查报告、审计底稿等复杂文档的工程化导出、版心溢出排查与质量交付。

---

## 一、解决的核心痛点

在银行信贷审批、财务风控及对公授信业务中，常见以下两类极高标准的交付需求：

1. **银行对账单明细按 CSV 重建**：原版 PDF 对账单格式固定、防伪标记齐备但缺乏业务批注或与调整后口径不符；本项目通过对原版 PDF 进行图文逆向实测，实现**“外观 100% 保持原版版式骨架，数据 100% 忠实还原 CSV 明细”**。
2. **Word 复杂信贷报告的高保真 PDF 导出与版心防溢出检查**：
   - 使用普通工具转换 PDF 时，经常出现**字体缺失、页边距被篡改、9列财务表格右界溢出裁切、表头跨页未重复、大面积空白脱节**等严重瑕疵；
   - 传统肉眼排查 15~20 页报告极易漏检关键数字截断；
   - 本仓库沉淀了基于 Word COM 安全副本导出、PyMuPDF 150 DPI 逐页切片、以及结合 BBox 几何算法的**全自动版心合规检查器**。

---

## 二、功能特性

- ✅ **对账单像素级克隆**：A4 网格、10 列等宽坐标、行距、表头带、红色标题、账户信息块全部来自原版实测，并具备自动模板探测。
- ✅ **字体度量与子集化嵌入**：原生内嵌 STSong（华文宋体/SimSun），字体度量逐字一致，离线完美渲染，生成文件体积小。
- ✅ **CSV 损坏智能修复**：自动识别并修复 Excel 另存导致的时间斜杠/丢秒、长账号科学计数法（`6.217E+18`）截断等问题；支持交易秒数 `:00` 随机化为 `01~59` 秒。
- ✅ **信贷报告 Word COM 高保真导出**：采用独立临时副本隔离机制，杜绝 Office 运行时对原文档的自动回写污染（如误创空页眉等缺陷）。
- ✅ **逐页高清预览图生成**：自动调用 PyMuPDF 生成 150+ DPI 高清 PNG 预览切片，专供视觉核查与多模态 Agent 终审。
- ✅ **自动化版心与视觉溢出排查**：自动检测各页物理边缘溢出、相较原版右界漂移、大面积空白脱节异常，输出结构化 PASS/FAIL 诊断。

## 五、快速上手指南

### 5.1 场景一：银行交易明细 CSV → 原排版 PDF 重建

```bash
# 1. （可选）对账单时间秒数随机化
python scripts/randomize_seconds.py "2025年版_九江银行交易明细清单.csv"

# 2. 合成替换版 PDF
python scripts/make_statement.py "2025年版_九江银行交易明细清单.csv" "交易明细清单-2025.5.1-2025.12.31.pdf"

# 3. 四层严格质量校验（内容/几何/网格/像素静态区）
python scripts/verify_statement.py "2025年版_九江银行交易明细清单.csv" "交易明细清单-2025.5.1-2025.12.31.pdf" "交易明细清单-2025.5.1-2025.12.31-明细按CSV替换版.pdf"
```

### 5.2 场景二：Word 信贷调查报告导出 PDF、切片生成与版心检查

```bash
# 1. 高保真导出 PDF 并生成逐页 150 DPI 高清预览图
python scripts/render_docx_to_pdf.py "精心续授信报告_2026更新版.docx" "精心续授信报告_2026更新版.pdf" "_preview"

# 2. 自动化版心与视觉溢出排查
python scripts/inspect_layout_and_box.py "精心续授信报告_2026更新版.pdf"

# 3. 对比原版基线 PDF 检查版面漂移（可选）
python scripts/inspect_layout_and_box.py "精心续授信报告_2026更新版.pdf" "精心续授信报告_原版.pdf"
```

## 六、关键参数标准参考

| 维度 | 参考标准 / 参数值 | 适用说明 |
|---|---|---|
| **页面基准** | 标准 A4（595.28 × 841.89 pt） | 210 × 297 mm |
| **信贷报告标准页边距** | 左/右 76.55 pt，顶 85.05 pt，底 56.7 pt | 版心净可用宽度约 442.2 pt (8844 twips) |
| **超多列表格安全宽度** | 建议总宽 ≤ 8750 twips (437.5 pt) | 9 列及以上财务报表需显式指定列宽，防物理越界 |
| **切片分辨率** | 150 DPI（约 1240 × 1754 像素） | 保证小五号（9 pt）及六号字体极佳锐度与可读性 |
| **对账单表头线位置** | 首页 y=133.8 / 146.8 pt，续页 y=35.8 pt | 10 列等宽网格，列宽 52.3 pt，黑边 0.5 pt |

## 七、实战经验与避坑要点

1. **规避 Word 自动污染**：使用 `python-docx` 操作报告时，切勿随意访问 `section.header`，否则可能无意中触发 Word 生成空页眉导致公文格式毁损；导出时务必使用 `render_docx_to_pdf.py` 的临时副本隔离机制。
2. **多模态 Agent 视觉复核闭环**：先由 `inspect_layout_and_box.py` 做全域坐标机器初筛，再由 Agent 使用视觉工具核验切片中表格跨页重复表头、下划线及高亮标注是否完整，兼具机器精确度与人类直觉审查。
